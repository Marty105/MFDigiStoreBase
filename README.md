DigiStore is an application which allows buyers and sellers to buy and sell a wide range of digital products. This application also allows site administrators to manage user profiles, and manage and approve product listings. 

****This is a draft app with only some features built out**

**Built**
* Signup
* Login
* Logout
* Update profile
* Add product
* View product
* Edit product

* **Not built**
* Administrator portal
* Search function
* Full landing page
